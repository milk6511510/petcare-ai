# 《PetCare AI 拍立得寵物護理》初步產品企劃與規格書 (PRD)

---

## 一、 產品定位與核心痛點

### 1.1 產品定位
* **產品名稱**：PetCare AI（拍立得寵物護理）
* **定位**：專為多寵物與多成員家庭打造的**「一秒拍照轉錄」醫囑排程與家庭共享聯絡簿**。
* **App Store / Google Play 分類**：`Productivity`（生產力工具）/ `Lifestyle`（生活風格），**絕不歸類為 Medical（醫療）**。

### 1.2 核心痛點解決
1. **餵藥重複 / 遺忘**：多位家人（如夫妻、室友、父母）輪流照護，常常「以為對方餵過了」或「重複餵兩次」。
2. **手動輸入極度繁瑣**：慢性病毛孩動輒 3~5 種藥物，劑量、飯前飯後、時間軸各異，手動打字輸入極易放棄。
3. **病歷零散遺失**：複診時無法精準向獸醫師回報「這兩週的用藥依從性與食慾精神狀況」。

## 二、 法律合規與 Safe Harbor 安全架構（最高優先級）

為完全符合《獸醫師法》第 11 條、第 30 條及《動物用藥品管理法》第 19 條，產品嚴格劃定紅線與安全邊界：

```
【合法安全區 (Safe Harbor) - 產品核心】
實體醫院開出的紙本藥袋 / 處方標籤 ──► 相機拍照 ──► 視覺 OCR 提取文字 ──► 轉為本地行事曆鬧鐘 ──► 家人打卡同步

【絕對禁止區 (Prohibited Zone) - 系統嚴格阻斷】
✕ 禁止 AI 自主診斷病症（如拍眼屎推測結膜炎）
✕ 禁止 AI 自主推薦藥品或推算未經醫囑的用藥劑量
✕ 禁止在 App 內販售、代購或分裝任何動物用處方藥與非處方藥
```

### 2.1 強制免責與宣告流程
1. **新手引導宣告 (Onboarding Consent)**：首次開啟 App 必須簽署《使用者健康紀錄守則》，確認本 App 僅為排程筆記工具，不具任何醫療診斷功能。
2. **掃描介面固定警語**：「本功能僅協助轉錄動物醫院開立之藥袋文字，請嚴格遵照主治獸醫師醫囑服藥。」

## 三、 核心功能架構與使用者旅程 (User Journey)

### 3.1 核心功能模組
1. **拍立得藥袋掃描儀 (Snap & Log OCR)**：
   * 調用手機相機，框選藥袋或處方明細。
   * OCR 自動辨識：藥品名稱、服用頻率（如每日兩次）、服用方式（飯前/飯後）、總天數。
   * **人機協同確認頁**：辨識結果以卡片呈現，飼主確認無誤後「一鍵生成服藥時間軸」。
2. **多成員家庭同步儀表板 (Family Sync Hub)**：
   * 一個家庭代碼（Family Code）綁定多隻毛孩與多位照護者。
   * 推播通知（Push Notification）支援互動按鈕：成員餵完藥後，在通知上直接點擊「已餵藥」，即刻同步並消除其他成員的待辦提醒。
3. **寵物專屬照護時間軸 (Pet Timeline)**：
   * 整合體重走勢、驅蟲週期（心絲蟲/外用滴劑）、疫苗提醒。
4. **回診摘要一鍵匯出 (Vet Report Export)**：
   * 將指定區間的「用藥遵從率」、「精神食慾打卡」一鍵生成清晰簡明的 PDF 報表，供實體看診時出示給獸醫師。

## 四、 商業變現模型 (Monetization & Paywall)

採用 **Freemium + 訂閱制（聚焦家庭共享與無限掃描）**：

| 方案等級 | 價格設定 | 功能權限 |
| :--- | :--- | :--- |
| **免費版 (Free Tier)** | \$0 | 1 隻寵物檔案、每月最多 3 次拍照辨識、單人使用（無家庭同步）、歷史紀錄保留 14 天。 |
| **PRO 家庭週訂閱 (Weekly)** | **NT\$ 150 / 週 (\$4.99)** | 無限次拍照辨識、無上限寵物檔案、全家成員即時推播同步、完整 PDF 匯出（衝動急需期高轉換）。 |
| **PRO 家庭年訂閱 (Annual)** | **NT\$ 1,290 / 年 (\$39.99)** | 包含週訂閱所有功能，贈送 3 個月免費，適合慢性病長期照護家庭。 |

## 五、 成長行銷與獲客腳本庫（短影音 Hooks）

由 **Echo（腳本）** 與 **Vance（剪輯）** 執行的短影音爆款主線：

* **Hook 1（家庭內疚痛點）**：
  * *畫面*：夫妻下班回家，妻子問：「你餵狗吃藥了嗎？」丈夫愣住：「我以為妳餵了！」鏡頭特寫小狗無辜委屈的臉。
  * *轉折*：拿出手機，用 PetCare AI 拍照藥袋，直接設定「全家連線」，誰餵過一秒看懂。
* **Hook 2（繁瑣打卡對比）**：
  * *畫面*：左邊傳統備忘錄手動打字 5 分鐘還打錯劑量；右邊 PetCare AI 鏡頭「咔嚓」一下，3 秒鐘全週鬧鐘自動排好。

## 六、 團隊執行分工規劃

* **Rex (PM)**：制定 MVP 功能範圍，確保各國 App Store 審查政策與免責合規文字覆核。
* **Iris (UI/UX)**：設計極簡高對比相機掃描介面、家庭成員同步打卡元件庫。
* **Neo (Mobile)**：以 Flutter 開發雙平台相機模組、離線本地 SQLite 快取與 iOS Live Activity / Dynamic Island 即時動態。
* **Drake (後端)**：整合 Google Cloud Vision / Azure OCR 介面，設計 WebSocket 即時推播與家庭多端狀態同步。
* **Rigel (QA)**：重點驗證模糊拍照容錯率、斷網環境下推播補發，以及雙平台 IAP 內購退款邏輯。
